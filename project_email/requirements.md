# Requirements - project_email

## 用户需求
- 24 小时在线验证码收取，不依赖 Windows 开机
- 优先部署在云端服务器
- 常用邮箱类型：126、Gmail、Outlook、QQ
- 不使用代理
- 用途聚焦：验证码接收与即时推送

## 功能需求
- 多邮箱并发监听（IMAP IDLE）
- 秒级触发新邮件处理
- OTP 提取与格式化
- 推送到飞书私聊
- 去重与防重复提醒

## 非功能需求
- 凭据最小暴露（应用专用密码）
- 高可用（systemd 自动拉起）
- 可观测（最小必要日志）
- 可扩展（新邮箱类型可快速添加）

## 安全约束
- 不在仓库存储真实密码/API Key
- 不落盘完整敏感邮件正文（默认）
- 仅记录必要元数据（发件人/主题哈希/时间）
