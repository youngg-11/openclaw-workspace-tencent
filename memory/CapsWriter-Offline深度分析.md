# CapsWriter-Offline 深度分析报告

> 生成时间: 2026-03-13

---

## 一、产品概述

**CapsWriter-Offline** 是一款专为 Windows 打造的**完全离线语音输入工具**，由开发者 HaujetZhao 创建和维护。

- **GitHub**: github.com/HaujetZhao/CapsWriter-Offline
- **Stars**: ⭐ 4,917
- **License**: 开源
- **平台**: Windows 10/11 (64位)

### 核心理念
> "按住 CapsLock 说话，松开就上屏。就这么简单。"

追求**完全离线**、**响应极快**、**高准确率**且**高度自定义**的语音输入体验。

---

## 二、核心特性详解

### 2.1 语音输入

| 特性 | 说明 |
|------|------|
| **触发方式** | 按住 CapsLock 键 或 鼠标侧键X2 |
| **工作方式** | 说话松开后自动上屏 |
| **智能标点** | 默认自动去除末尾逗句号 |
| **录音模式** | 支持对讲机模式（按住说话）和单击录音模式 |

**使用流程**：
1. 按住 CapsLock
2. 说话
3. 松开 CapsLock
4. 文字自动输入到光标位置

---

### 2.2 文件转录

支持将音视频文件拖入客户端，自动生成：
- **字幕文件** (.srt)
- **纯文本** (.txt)
- **时间戳** (.json)

---

### 2.3 数字 ITN (逆文本正规化)

自动将口语数字转换为标准格式：
- 「十五六个」→ 「15~16个」
- 「二零二六年三月十三号」→ 「2026年3月13号」
- 支持各种复杂数字格式

---

### 2.4 热词系统

| 热词类型 | 文件 | 功能 |
|----------|------|------|
| **服务端热词** | hot-server.txt | 语境增强识别（建议性） |
| **客户端热词** | hot.txt | 强制替换（音素模糊匹配） |
| **正则替换** | hot-rule.txt | 正则表达式精准替换 |
| **纠错记录** | hot-rectify.txt | 辅助LLM润色 |

**RAG 检索增强**：热词识别支持音素级 fuzzy 匹配，发音稍有偏差也能识别。

---

### 2.5 LLM 角色系统

集成大语言模型，支持多种自定义角色：

| 预置角色 | 功能 |
|----------|------|
| 润色 | 优化文本表达 |
| 翻译 | 多语言翻译 |
| 代码助手 | 编程相关辅助 |

**使用方式**：在语音开头说出角色名，例如：
> 「翻译，今天天气好」→ 自动翻译为英文

**LLM 后端选择**：
- **本地模型**：通过 Ollama 运行（如 gemma3:4b, qwen3:4b）
- **在线模型**：DeepSeek 等 API

**高级功能**：支持读取屏幕选中内容进行 AI 处理

---

### 2.6 支持的 ASR 模型

| 模型 | 特点 | 准确率 | 速度 |
|------|------|--------|------|
| **Qwen3-ASR-1.7B** | 自带标点，独显加速极快 | ⭐⭐⭐⭐⭐ | ~100ms |
| **Fun-ASR-Nano** | LLM Decoder 智能意图识别 | ⭐⭐⭐⭐⭐ | ~200ms |
| **SenseVoice** | CPU 上极快 | ⭐⭐⭐⭐ | ~100ms |
| **Paraformer** | 准确率高 | ⭐⭐⭐⭐ | ~100ms |

---

### 2.7 其他特性

| 特性 | 说明 |
|------|------|
| 托盘运行 | 可完全隐藏前台窗口 |
| 日记归档 | 按日期保存语音及识别结果 |
| 录音保存 | 所有语音保存为本地音频文件 |
| C/S 架构 | 服务端与客户端分离 |
| 开机启动 | 支持放入启动文件夹 |
| UDP 广播 | 支持扩展控制 |

## 三、技术架构

### 3.1 核心技术

| 组件 | 技术 |
|------|------|
| ASR 引擎 | Sherpa-ONNX, FunASR, SenseVoice, Paraformer |
| 加速方案 | DirectML (显卡), Vulkan (推理) |
| 语音合成 | pyttsx3 |
| 热词匹配 | 音素级模糊匹配算法 |

### 3.2 系统要求

| 组件 | 最低要求 |
|------|----------|
| 系统 | Windows 10/11 (64位) |
| 内存 | 8GB+ |
| 显存 | 1.6GB+ (启用Vulkan加速) |
| 麦克风 | 建议 USB 桌面麦克风 |

### 3.3 安装方式

1. 下载软件本体 + 模型包
2. 解压放入 models 文件夹
3. 双击 start_server.exe (服务端)
4. 双击 start_client.exe (客户端)
5. 按住 CapsLock 说话

## 六、总结

### CapsWriter-Offline 优势

1. **完全离线** - 不依赖网络，隐私安全
2. **响应极快** - GPU 加速最低 100ms
3. **功能全面** - 热词、LLM 角色、数字转换
4. **高度自定义** - 配置文件丰富
5. **社区活跃** - 4,917 Stars，持续更新
