# Handbag OOTD 拍摄提示词技能

## 核心规则

✅ 只描述动作，不描述模特特征  
✅ OOTD 展示动作，自然真实  
✅ 构图：Lower face visible = waist up / shoulders down（❌ 禁用 chest up）  
✅ 主体：以包包为主  

---

## 提示词结构

```
[设备] [拍摄风格] [运镜方式], [主体位置]. [画面效果]. [光线与细节].
```

### 设备
```
Shot on iPhone 17 Pro Max
```

### 拍摄风格（任选其一）
```
Casual handheld camera
Natural documentary style  
Lifestyle vlog aesthetic
Street snap aesthetic
Cinematic documentary
```

### 运镜方式
```
orbits / pans / tracks / dolly / tracking shot / handheld steady shot / slow motion
```

### 主体位置
```
handbag perfectly centered
bag remains in focus
bag takes up 2/3 frame
```

### 画面效果
```
No professional bokeh, realistic dynamic range
shallow depth, clean background
```

### 光线与细节
```
natural indoor daylight, bag texture detailed
soft natural lighting, warm tones
bright ambient light, crisp details
```

---

## 输出格式

- 语言：英文
- 时长：10-15秒
- 数量：3个脚本
- 每个脚本带完整中文翻译

---

## 使用示例

**输入**：handbag OOTD, casual style

**输出**：

### Script 1
**English:**
Shot on iPhone 17 Pro Max, Casual handheld camera, orbits around the model showing the handbag from multiple angles, handbag perfectly centered. No professional bokeh, realistic dynamic range. natural indoor daylight, bag texture detailed. 12 seconds.

**中文翻译：**
iPhone 17 Pro Max 拍摄，手持相机自然环绕，从多角度展示包包，包包居中。无专业虚化，真实动态范围。室内自然光，包包纹理清晰。12秒。

## 禁止事项

❌ 禁止使用 "chest up" 构图  
❌ 禁止描述模特的外貌特征  
❌ 禁止使用 "model" 一词，改用 "subject" 或 "the bag"  
❌ 禁止过度美化的虚化效果
